# UPI Transactions Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze UPI transaction data and provide insights into transaction volumes, payment trends, success rates, cashback, and potential fraud. It enables users to monitor payment performance across multiple dimensions and identify patterns for data-driven decision-making.

## Key Features
- **Transaction KPIs:** Tracks total transactions, transaction amount, cashback, success rate, and suspected fraud.
- **Time-Based Analysis:** Visualizes transaction trends by date, hour, and day of the week.
- **Payment Insights:** Compares transactions across UPI applications, banks, transaction statuses, and payment types.
- **Geographical Analysis:** Examines transaction distribution across Indian states.
- **Interactive Filters:** Enables dynamic exploration of data by customer, location, merchant, and transaction-related attributes.

## Tools & Technologies
- Microsoft Power BI
- Data Cleaning and Transformation
- Data Visualization and Dashboard Design
- Excel

## Outcome
Developed a comprehensive analytical dashboard to simplify UPI transaction monitoring, identify payment trends, and support performance evaluation through interactive visualizations and key performance indicators.
